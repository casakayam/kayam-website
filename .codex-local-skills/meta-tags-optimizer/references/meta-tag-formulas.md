# Meta Tag Formulas

## Title Patterns

- `Primary Keyword | Brand`
- `Primary Keyword: Main Benefit | Brand`
- `How to [Outcome] with [Topic] | Brand`
- `[Topic] for [Audience] | Brand`

## Meta Description Patterns

- `[Primary keyword] for [audience]. [Main benefit]. [CTA].`
- `Learn [outcome], avoid [pain point], and [benefit]. [CTA].`
- `Discover [topic] with [specific differentiator]. [CTA].`

## Length Guidance

- Title: usually target about 50-60 characters
- Meta description: usually target about 150-160 characters
