# On-Page SEO Audit Templates

Use one shape throughout: evidence -> checks -> issues -> fix -> score.

## Shared Conventions

- Status: `PASS`, `RISK`, `FAIL`
- Severity: `P0` blocks or strongly suppresses performance, `P1` materially weakens performance, `P2` hygiene
- Section scores: `/10`
- Final score: `/100`

## Step 1: Setup

Capture:
- URL or file path
- target keyword
- inferred keyword if needed
- page type
- business goal
- evidence source

## Step 2: Title Tag

Report:
- current title
- character count
- keyword present or missing
- front-loaded or not
- intent match
- clickability
- recommended title
- score

## Step 3: Meta Description

Report:
- current meta description
- character count
- keyword present or missing
- CTA present or missing
- accuracy and intent match
- recommended meta description
- score

## Step 4: Headers

Report:
- H1 count
- H1 keyword coverage
- H2/H3 hierarchy quality
- missing subtopics
- score

## Step 5: Content Structure

Report:
- approximate length
- readability and chunking
- intro answer quality
- use of examples, lists, tables, FAQs, CTA
- freshness or proof gaps
- score

## Step 6: Keyword Usage

Check whether the primary keyword appears in:
- title
- meta
- H1
- first 100 words
- H2/H3s
- URL
- image alts

Then report:
- secondary term coverage
- overuse risk
- score

## Step 7: Internal Links

Report:
- count
- anchor text quality
- contextual relevance
- obvious missing links
- broken or misdirected links if observed
- score

## Step 8: Images

Use this table when helpful:

| Image | Alt | Filename | Format/Size | Lazy Load | Status | Fix |
|---|---|---|---|---|---|---|
| [image] | [alt or missing] | [filename] | [format/size] | [yes/no] | [PASS/RISK/FAIL] | [fix] |

Then give an image score.

## Step 9: Technical On-Page

Report:
- URL slug quality
- canonical presence
- schema presence
- mobile or speed observations only if actually measured or clearly visible
- score

## Step 10: Quick Quality and Trust Scan

Flag:
- weak first-hand evidence
- missing author identity
- missing disclosures where relevant
- stale dates or unsupported claims
- accessibility issues obvious from markup structure

Do not convert this into a publish-readiness verdict.

Use this scorecard:

Then finish with:
- overall score `/100`
- top `P0`, `P1`, `P2`
- quick wins
- suggested title and meta
