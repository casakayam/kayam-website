# On-Page SEO Scoring Rubric

Score each section independently, then combine them into an overall score out of 100.

## Weighted Scorecard

| Section | Weight | Max | Core checks |
|---|---:|---:|---|
| Title tag | 15% | 15 | Keyword present, early placement, 50-60 chars, unique, compelling, intent match |
| Meta description | 5% | 5 | Natural keyword use, 150-160 chars, CTA, unique, accurate summary |
| Header structure | 10% | 10 | One H1, logical nesting, H2 coverage, descriptive subheads |
| Content structure | 25% | 25 | Appropriate length, breadth, formatting, examples, freshness, useful proof |
| Keyword optimization | 15% | 15 | Keyword appears in key page elements, related terms present, no stuffing |
| Internal/external links | 10% | 10 | Relevant links, descriptive anchors, enough contextual linking, no obvious breakage |
| Image optimization | 10% | 10 | Descriptive filenames, useful alt text, efficient formats and sizes, lazy loading where appropriate |
| Page-level technical | 10% | 10 | Clean slug, canonical, schema presence, mobile-friendly observations when measurable |

## Benchmarks

### Content Length by Query Type

| Query type | Strong | Partial | Weak |
|---|---:|---:|---:|
| Informational | 1500+ | 500-1499 | <500 |
| Commercial | 1200+ | 400-1199 | <400 |
| Transactional | 500+ | 200-499 | <200 |
| Local | 400+ | 150-399 | <150 |

### Keyword Density

| Density | Interpretation |
|---|---|
| 0.5-2.0% | Generally healthy |
| 2.0-2.5% | Slight overuse risk |
| 2.5-3.0% | High overuse risk |
| >3.0% | Likely stuffing |
| <0.5% | Light usage unless query naturally needs less repetition |

### Internal Link Count

| Content length | Minimum | Healthy range |
|---|---:|---:|
| <500 words | 2 | 2-4 |
| 500-1000 | 3 | 3-6 |
| 1000-2000 | 4 | 5-10 |
| 2000+ | 5 | 8-15 |

## Accessibility Overlay

Treat obvious accessibility failures as high-priority because they affect usability and search quality:
- missing or bad alt text
- broken heading structure
- weak focus states if observed
- unlabeled custom controls in supplied markup

## Grade Bands

| Score | Grade | Meaning |
|---:|---|---|
| 90-100 | A+ | Exceptional; minor tweaks only |
| 80-89 | A | Strong; a few opportunities |
| 70-79 | B | Good; several improvements needed |
| 60-69 | C | Average; meaningful work needed |
| 50-59 | D | Weak; major issues present |
| <50 | F | Poor; substantial overhaul needed |

## Resolution Shortcuts

| Issue | Priority | Quick fix |
|---|---|---|
| Missing title | P0 | Add `Primary Keyword: Benefit | Brand` |
| Title too long | P1 | Remove filler and move brand to the end |
| Missing meta | P1 | Write a clear summary plus one CTA |
| Missing H1 | P0 | Add one H1 with the target topic |
| Multiple H1s | P1 | Keep one H1 and demote the rest |
| Thin content | P0 | Add missing subtopics, examples, FAQ, and proof |
| Keyword stuffing | P1 | Reduce exact matches and add natural variants |
| Missing internal links | P1 | Add contextual links to relevant pages |
| Missing alt text | P1 | Add functional alt text; avoid keyword lists |
| Missing schema on eligible page | P2 | Add the page-appropriate schema type |
