# Pre-Migration Technical SEO Playbook

Use this when the user is planning a platform, framework, domain, or URL-structure migration.

## Audit Sequence

1. Baseline snapshot
2. URL inventory
3. Redirect mapping
4. Canonical and hreflang review
5. Internal link and nav review
6. Staging safeguards
7. Launch-day checklist
8. T+1 and T+7 verification

## High-Risk Failure Modes

- staging `noindex` leaks to production
- redirects missing for high-value URLs
- protocol or host normalization breaks
- canonicals still point to old URLs
- sitemap contains redirected or blocked URLs
- internal links still target old paths
